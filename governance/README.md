# Public governance record

- `rfcs/` contains durable proposals and outcomes.
- `votes/` contains roll-call decisions and reasons.
- `treasury/ledger.csv` is the append-only public money ledger.

Discussion may begin in GitHub issues, but accepted RFCs and completed votes are committed here so every clone retains the record. Correct a ledger error with a reversing row and replacement row; never rewrite a received or spent transaction.
