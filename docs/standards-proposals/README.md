# Standards proposals

This directory is the public staging area for genuinely novel web-platform capabilities before Astra enables them by default.

The v1.20.0 audit found **no such capability**. Boosts, resource reporting, the local assistant, Peek, shell IPC, and sync are user-agent or service features built without an Astra-only API on web pages. Consequently there is no proposal to submit for this release; manufacturing one would incorrectly turn private browser UI into a web primitive.

A future proposal must state the user need, prior art, threat and fingerprinting analysis, interoperability plan, tentative specification text, tests, and intended W3C or WHATWG venue. Its matching entry in `docs/standards-audit.json` must link the note.
