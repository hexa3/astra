# Astra 2.0.0

Astra 2.0 turns the project's “Linux of browsers” goal into things a user can inspect and exercise. The release is MPL-licensed, produces independently reproducible Linux binaries, puts the privileged core behind API 2.0, stores non-secret configuration as TOML, includes an offline CLI and an identity-free self-hosted sync stack, and ships two deliberately different shells over one core.

## Download the right build

The `default` Linux x64 archive contains the full vertical-tab interface. The `minimal` archive contains a sparse horizontal browser shell without the sidebar, command bar, panels or assistant UI. Both contain the same byte-for-byte `astra-core` executable. Extract either archive and run `./astra/astra-browser`.

Each archive has an adjacent `.sha256` manifest. The release workflow builds both archives twice on separate clean runners and refuses to publish if either pair differs. After publication, a separate release-event job rebuilds the tag and compares the downloaded public archives with those fresh bytes.

## What to inspect

- `LICENSE`, `GOVERNANCE.md` and `FUNDING.md` define file-level copyleft, public decisions and funding boundaries.
- `REPRODUCIBLE_BUILDS.md` gives the clean-room rebuild and comparison procedure.
- `CORE_API.md` and `VARIANTS.md` explain the core/shell boundary and the two official products.
- `CONFIGURATION.md` documents TOML layout, secret exclusions and every `astractl` operation.
- `SYNC.md` covers standalone deployment, pairing, encryption, visible metadata and the threat model.
- `STANDARDS.md` and `docs/standards-audit.json` inventory every custom surface and keep Astra-only APIs out of ordinary pages.
- `docs/decisions.md` closes the phase with a pillar-by-pillar account of what is proven and what remains unfinished.

## Verification and limits

The candidate passed 57 unit, security and architecture tests; 17 sandboxed Electron browser/privacy tests; native lifecycle and MV3 execution tests; production builds for both shells; and native Windows x64, macOS arm64 and macOS x64 package runs. Reproducibility currently applies to the complete runnable Linux x64 archives, not AppImage, Debian, Windows or macOS installer formats. Astra is still an unincorporated project with a bootstrap steward, sync has not received a third-party cryptographic audit, and the current standards audit found no novel web primitive worth submitting. Those are boundaries of the release, not claims hidden in small print.
