# Astra 0.1.0 — first Linux alpha

A working browser foundation, shipped approximately 32 minutes after the build
started. This is an early alpha, not the final 24-hour release.

Browse real HTTP/HTTPS pages with back, forward, reload, search and vertical tabs.
Save bookmarks and history in an encrypted SQLite vault, using an OS key store
or an explicit passphrase. Saved tabs restore on selection. Choose dark, light
or system appearance. Inspect actual request and tracker-blocking counts in
“Behind the page.”

Privacy defaults include a bundled basic tracker host list, tested third-party
HTTP/document cookie blocking, denied sensitive site permissions, no telemetry
or updater, and memory-only website storage. **Website logins do not survive
quitting.** Click the storage status at the bottom to set up or unlock encrypted
browser records when a secure key store is unavailable.

Linux x64 downloads:

- `Astra-0.1.0.AppImage`: mark executable and launch.
- `astra-browser_0.1.0_amd64.deb`: install with your Debian/Ubuntu package manager.
- `SHA256SUMS`: verify artifact hashes.

Verified on this Arch Linux desktop: source build, four unit tests, three
Electron integration tests, live example.com rendering, passphrase restore,
cookie isolation, packaged executable launch, and direct AppImage launch with
sandbox enabled. Debian archive structure was inspected; installation on a
Debian/Ubuntu host has not been tested. npm audit reports zero findings.

Not included yet: workspaces, command palette, split view, tab hibernation,
extensions, per-site customization, AI, native Windows/macOS packages, or a full
accessibility and compatibility audit. Downloads use Electron's native save
behavior; there is no download manager yet. The tracker list is deliberately
small. Do not treat this alpha as a hardened substitute for a mature browser.
